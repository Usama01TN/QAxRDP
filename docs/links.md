# References

- [Remote Desktop Services - Win32 apps (Microsoft Docs)](https://docs.microsoft.com/en-us/windows/win32/termserv/terminal-services-portal):
  the MsTscAx control, its interfaces (`IMsRdpClient*`, `IMsTscAxEvents`), properties and disconnect reasons.
- [rdpappcontainerclient.h header - Win32 apps (Microsoft Docs)](https://docs.microsoft.com/en-us/windows/win32/api/rdpappcontainerclient/):
  RDP app container client API.
- [Devolutions MsRdpEx - Microsoft RDP Client Extensions](https://github.com/Devolutions/MsRdpEx):
  extensions and hooks for the Microsoft RDP client.
- [ManyQt](https://pypi.org/project/ManyQt/): the PyQt / PySide compatibility layer QAxRDP is written on.
- `MsTscAx-control-reference.html` (this folder): the documentation generated by `QAxWidget.generateDocumentation()`
  for `MsTscAx.MsTscAx.11` (slots, signals, properties and enumerations of the control).
- `API.md` (this folder): reference of every settings property exposed by QAxRDP.
